# Introdução ao Python — Codefinity

Repositório de estudos práticos desenvolvido durante minha formação em Python na Codefinity. Os exercícios registram minha evolução nos fundamentos da linguagem e na resolução de problemas.

## Conteúdos praticados

- variáveis e tipos de dados;
- operações matemáticas;
- estruturas condicionais;
- operadores de associação;
- desafios práticos de lógica de programação.

## Organização

```text
getting_started/          primeiros exercícios e operações
variables_and_types/      variáveis, tipos e desafios práticos
conditional_statements/   condições e operadores
```

## Tecnologias

- Python 3
- Git e GitHub

## Objetivo

Consolidar fundamentos de Python por meio de exercícios progressivos, mantendo um histórico público e organizado do aprendizado.
